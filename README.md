# 📍 MekanBul Backend Projesi

Bu proje, **Süleyman Demirel Üniversitesi** ve çevresindeki mekanları, puanları ve yorumları yöneten bir RESTful API altyapısıdır. Veriler **MongoDB Atlas (Cloud)** üzerinde güvenle saklanmaktadır.

---

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Amaç |
|-----------|------|
| ![NodeJS](https://img.shields.io/badge/Node.js-43853D?style=for-the-badge&logo=node.js&logoColor=white) | Sunucu tarafı çalışma ortamı |
| ![Express.js](https://img.shields.io/badge/Express.js-404D59?style=for-the-badge) | Web framework |
| ![MongoDB](https://img.shields.io/badge/MongoDB-4EA94B?style=for-the-badge&logo=mongodb&logoColor=white) | NoSQL Bulut Veritabanı (Atlas) |
| ![Mongoose](https://img.shields.io/badge/Mongoose-880000?style=for-the-badge&logo=mongoose&logoColor=white) | Veri modelleme (ODM) |

---

## 🌟 Öne Çıkan Özellikler

* ☁️ **Cloud Database:** Veriler yerel diskte değil, MongoDB Atlas bulut sunucularında tutulur.
* 🗺️ **Konum Bazlı Veri:** Mekanların koordinat bilgileri (GeoJSON) ile yönetimi.
* 💬 **Yorum Sistemi:** Kullanıcıların mekanlara yorum yapıp puan verebildiği altyapı.
